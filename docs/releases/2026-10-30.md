# Published metric consistency correction

The Neisseria meningitidis v1.1 export retained July 2025 summary data and warning limits inferred by an obsolete exporter. Its creation commit specifies inheritance from v1.0 with only the genome-size failure upper limit changed to 2.3 Mb. Restore the 20 May 2026 Cluster3 baseline and retain that existing pin. The native genome-size warning interval is 2.0–2.3 Mb. Other species and scheme thresholds are unchanged.

See [source provenance and hashes](2026-10-30-nmen-provenance.json). Reproducing the cached baseline matched every verdict and reason across 35,816 rows. Applying the existing upper pin gives 30,660 PASS, 3,240 WARN and 1,916 FAIL: 39 WARN become FAIL; no PASS changes. This is an export from cached metric rows, with no model refit or genome processing. All N. meningitidis v1.1 reference lists, plots, summaries, classification files, manifest and aggregate exports accompany the release.

The renderer now preserves published GC precision and converts GC standard deviations using the distribution's source units. External single-tier schemes explain their absent warnings. The manifest builder uses native warning columns, with actual summary WARN columns as a legacy fallback, and never constructs warnings from failure limits or arbitrary buffers. CI checks every indexed scheme and rendered table.

The corresponding manuscript and review documents were not edited. Their frozen N. meningitidis derivation-summary entries need reconciliation with the corrected 31,977 non-RefSeq and 139 RefSeq records before circulation. This does not imply reclassifying all other species or changing the separate classification cohort in Supplementary Table 4.
